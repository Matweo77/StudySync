# 📚 StudySync - Landing Page para Gestión de Estudio

##  Características Principales

* **Hero Section interactivo:** Vista previa funcional del panel de control del estudiante con barra de progreso semanal, tareas pendientes y temporizador en *Modo Enfoque*[cite: 5].
* **Captura de Leads / Acceso Anticipado:** Formulario para registro de correo académico con llamado a la acción "Quiero probarlo gratis"[cite: 5].
* **Secciones del Problema y Solución:** Bloques visuales enfocados en los dolores comunes del estudiante (acumulación de tareas, falta de foco, estrés) y cómo StudySync les ayuda a planificar[cite: 6, 7].
* **Navegación Fluida:** Menú superior con scroll a secciones de interés (*El problema*, *Solución*, *Beneficios* y botón de *Acceso anticipado*)[cite: 5].
* **Diseño Limpio y Responsive:** Interfaz moderna con paleta de colores pensada para la productividad[cite: 5, 6, 7].

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React.js (`.jsx`)
* **Estilos:** Tailwind CSS
* **Build Tool:** Vite
* **Componentes / Iconos:** Lucide React / Shadcn UI
